This project uses a Diagnostic Funnel Model.

Core logic:

1. Hook
2. Qualification
3. Emotional investment
4. Aha moment
5. Personalized solution
6. Strategic call or premium offer

When reviewing:

- Ensure each step builds psychological momentum.
- Ensure the quiz increases commitment.
- Ensure results feel tailored.
- Ensure transition to offer feels inevitable.

If the quiz only collects data but does not build desire, redesign it.
